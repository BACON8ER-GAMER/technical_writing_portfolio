The following examples are from my time at the University of Washington. These projects are from throughout the three different courses that are part of the program. Descriptions of each project are included below.

Implementing a Docs as Code Workflow for Technical Documentation

Audience: Technical writers or software engineers looking to improve documentation workflow to make it easier for technical writers and software engineers to collaborate on documentation

Project Role: Writer, HTML Production Specialist, Digital Archivist

Tools: Git, GitHub, Git Pages, Google Docs, Snagit, and Slack

Skills: Markdown, HTML, CSS, Research, Usability Testing, Accessibility Testing, and Group Collaboration

Process:

  • Weeks 1-2: Defined project goals and audience analysis
  • Weeks 3-4: Conducted user interviews and created a project plan
  • Weeks 5-6: Drafted the website content (GitHub Exercises section)
  • Weeks 7-8: Coded and implemented content into the website

Timeframe: 8 weeks
